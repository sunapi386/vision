基础设施分析

从挖矿到AI算力

中国基础设施指南：矿场哪些资产可以转用、哪些不能，以及真实的回本数据。

机会在哪里

现有矿场有三个对AI算力有价值的资产：

  1. 电力容量，已有稳定的供电合同（如河北0.59元/度）
  2. 物理基础设施：架空地板、冷却系统、备用发电机、安保
  3. 运维经验：懂得如何让数据中心7x24小时运转的人

这三个资产比矿机本身更有价值。厂房才是真正的资产，不是里面的芯片。

矿机不能跑AI

关键事实：S19矿机是SHA-256专用芯片(ASIC)，没有GPU，没有显存，没有CUDA核心，不能跑AI推理。这是硬件架构的限制，不是软件问题。

问题不是"现有矿机能不能跑AI？"答案是不能。问题是："能不能把GPU服务器放进现有厂房，省掉建设成本？"

能用的资产：厂房、电力、冷却系统、运维经验

不能用的资产：矿机芯片本身

现有设备的四个选择

A

继续挖矿（维持现状）

只要电费还能覆盖就继续。风险：难度在涨，设备老化，最多再挖1-2年。

B

卖掉矿机换GPU

在二手市场清仓ASIC矿机（5年以上设备折价严重）。所得用作购买GPU服务器的首付。

C

逐步过渡

用挖矿收入逐步购买GPU服务器，每季度买5-10台。自筹资金，无需外部融资，但增速较慢。

D

混合运营

一边继续挖矿，一边在空余位置装GPU。每退2台矿机(~6kW)，空出来的电够装1台GPU服务器(~5kW)。

回本时间取决于三个变量：利用率、硬件成本、补贴。没有哪个平台能做到100%利用率。按50-60%算比较靠谱。VastAI认证卖家通常做到70-85%。

怎么看这些表：现实回本周期在1.5到3.5年。B200虽然贵，但回本比H100快，因为每小时收入比例更高。政府补贴是最大的杠杆。

Token（令牌）销售模式

除了出租裸GPU时间，还可以运行推理服务器，按Token（AI处理的最小单位）计费出售API访问。这是Together.ai、DeepInfra、Fireworks的模式。

打个比方：卖GPU时间 = 出租毛坯房，卖Token = 出租精装房。

Token经济账：实际计算

小模型(8B)，1台H100，自有厂房（只算电费）：

月产Token数:    12,500 tok/s x 3,600 x 0.70 x 730 = ~230亿个
月电费:          3.5kW x 730小时 x 0.59元 = 1,506元 ($209)
月收入（按$0.20/百万Token）: 23,000M x $0.20 = $4,600 (~33,000元)
毛利率:          95%以上（边际成本就是电费）

大模型(70B)，1台H100，自有厂房：

月产Token数:    400 tok/s x 3,600 x 0.70 x 730 = ~7.4亿个
月电费:          同上 1,506元
月收入（按$0.30/百万Token）: 736M x $0.30 = $221 (~1,590元)
结论:            赚得少，因为大模型吃算力，产出慢

核心发现：自己有机器的话，卖Token比卖GPU时间赚得多。因为边际成本就是电费（在中国才1500元/月），而小模型(8B)卖Token月收入可达3-5万元/台。但前提是要会部署推理服务，还要有客户。

吞吐量估算基于 vLLM性能基准 和 NVIDIA TensorRT-LLM。

五个投资方案

方案一：只出租厂房（最低风险）

把厂房（电力+冷却+空间）租给AI算力公司。你当房东，租户自己带GPU服务器。

投入：基本为零（厂房已有）

收入：托管费，通常电价加价0.1-0.3元/度 + 空间租金

回本：立即（没有硬件投入）

风险：极低。不承担GPU贬值风险。收入不高但稳定可预期。传统托管模式。

方案二：小规模测试（10台服务器，依赖补贴）

买10台GPU服务器，挂VastAI等平台，测试3-6个月看利用率再决定是否扩大。

投入：210万-350万元（补贴前），105万-175万元（50%补贴后）

年收入(60%利用率)：~$273,000（197万元）GPU出租，或~$552,000（397万元）Token销售

回本(50%补贴)：~1.8年（GPU出租）或~11个月（Token销售）

风险：中等。GPU有3-5年使用寿命，利用率低于40%回本期会超过设备寿命。

关键前提：先确认补贴资格再买。

方案三：全面转型（100台服务器，市场规模）

整个厂房转型为GPU算力中心。需要大量资金，但能达到有市场意义的规模。

投入：2100万-3500万元（补贴前）

年收入(60%利用率)：~$2.73M（1970万元）GPU出租

回本(50%补贴)：~1.8年

风险：高。资金量大，GPU有贬值风险，利用率取决于市场需求。这个规模可以直接对接企业客户，不走平台，价格和利用率保障更好。

方案四：卖AI服务（最高利润，最复杂）

不卖裸算力，卖完整的AI推理服务（卖结果，不卖小时）。利润是裸算力出租的10-100倍。

投入：硬件 + 软件平台开发

单位利润：远高于裸算力

回本：可能不到1年，但需要软件能力

风险：复杂度最高。需要AI平台开发和维护能力。

方案五：Token路由器（轻资产中间商）

不自己跑AI，做算力中介。买家通过你的平台购买Token，你从不同GPU供应商采购算力，赚差价。

投入：平台开发费用，不需要买GPU

收入：每笔交易抽成10-20%

回本：取决于交易量

风险：硬件风险低（不承担GPU贬值）。市场风险取决于聚合需求的能力。inference.ai就是这个模式。

选址分析

唐山（河北）

示例城市。优势：已有矿场基础设施、0.59元/度工业电价、距北京90分钟高铁。局限：不是东数西算指定枢纽，没有查到AI专项补贴。可用的政策是一般性高新企业税收优惠（15%企业税率 vs 25%），以及大型投资项目的个案谈判空间。参见唐山大数据规划。

东数西算枢纽

国家战略框架，将东部算力需求导向西部廉价电力地区。指定枢纽及其优势：

  • 贵州：水电充沛、气候凉爽，苹果/华为数据中心已入驻。10%硬件补贴（国产芯片）。电价低至0.30-0.35元/度。贵州算力激励政策
  • 内蒙古：风电+光伏，土地极便宜，与北京光纤连接好。合格设施电价0.26-0.35元/度。
  • 甘肃：可再生能源丰富，政府积极招商。电费补贴最高50%，但排除外国芯片。
  • 宁夏：与甘肃类似的可再生能源优势，国家指定枢纽。中卫是主要数据中心集群。

台州（浙江）

沿海替代方案，优势不同：靠近上海AI生态圈，浙江科技政策环境好，制造业基础扎实。电费较高（~0.70+元/度），但到主要市场的延迟更低。

选址取决于商业模式。如果做GPU出租（延迟不敏感的训练和批量推理），西部电价便宜的枢纽占优。如果做东部客户的实时推理服务，地理距离比电价更重要。

跨境考量

中国的GPU农场能不能把算力卖到海外？这是最高价值的场景，因为国际价格（$2-8/时/GPU）远高于国内。但有几个限制。

技术限制

  • 延迟：中美往返延迟通常150-250ms。训练和批量推理可以接受，但实时应用有问题。中国到东南亚30-80ms，更适合做实时服务。
  • 防火墙：国际带宽被限速，受深度包检测影响。VPN隧道增加开销且有合规风险。专线（CN2、IPLC）价格贵，需要运营商协议。
  • 带宽成本：中国的国际带宽是国内的5-10倍。大模型权重、训练数据等高吞吐量传输成本很高。

法律和监管

  • 硬件来源：H100/B200 GPU受美国出口管制，通过灰色渠道进入中国。在国际平台上公开这些GPU会暴露供应链，运营方可能想避免这种可见性。最新政策：BIS H200出口政策变化，H200对华出货
  • 数据主权：中国的数据本地化法律（《个人信息保护法》、《数据安全法》）限制某些类别的数据出境。国际客户将数据发送到中国GPU上可能面临其本国司法管辖的合规问题。
  • 平台政策：VastAI和RunPod接受全球卖家，但从中国设施获得认证和信誉分较难，因为网络可靠性是考量因素。

现实评估：从中国跨境出租GPU技术上可行，但运营上复杂。最强的使用场景是服务中国国内市场、有低延迟需求的东南亚客户、或作为全球算力网络中面向中国市场的节点。

不要做的事

  1. 不要假设100%利用率。没有哪个平台能做到。按50-60%算靠谱。
  2. 不要先买机器再申请补贴。补贴是回本1.8年和3.6年的区别。
  3. 不要以为矿机能跑AI。S19是专用芯片，不能跑AI。能用的是厂房和电力。
  4. 不要忽视GPU贬值。3年回本的硬件如果4年就过时，意味着只有1年纯利润期。
  5. 不要只看一个数字。回本时间取决于利用率、补贴、购价三个变量。看表格，不看单个估算。

建议的下一步

  1. 确认当前挖矿是否盈利。扣除电费后还有正现金流吗？如果没有，转型决策已经替你做了。
  2. 调查省级AI算力补贴政策。申请流程、资格条件、国产芯片要求。
  3. 在VastAI上注册，了解认证流程和目标GPU型号的利用率数据。
  4. 拿真实报价，通过国内渠道询B200或同级GPU服务器价格，包括国产替代方案（华为昇腾）的补贴资格确认。
  5. 先试方案一或小规模方案二（2-3台服务器），验证利用率后再投入大量资金。
  6. 3个月后复盘，基于测试利用率数据决定下一步。
