# Part III: The Pattern

By 1993, millions of people could browse the web, send email and transfer files. Almost nobody would type a credit card number into a browser, because everything crossed the network in cleartext. The network worked. Nobody trusted it with money. Then, in 1995, Netscape shipped SSL, and an internet economy became possible.

That is the pattern this part follows. In four revolutions (commerce, the internet, international banking, containerized software), an accountability layer followed the new capability. The capability comes first. The accountability infrastructure comes second. And in every case in this part, the accountability layer outlasted the tools it accounted for.

The agent economy is the current revolution. AI agents are autonomously reasoning, spending money, and producing conclusions that inform consequential decisions, all without a standardized accountability layer. If the pattern holds, this will change. What is still open is when, and whether it is designed intentionally or cobbled together from incompatible patches after the failures.
